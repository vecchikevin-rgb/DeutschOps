# DeutschOps 🇩🇪

> AI-powered German language learning pipeline — from audio lesson to structured 
> study materials, automatically.

Built by a production manager transitioning into Swiss pharma (Basel area), 
learning German from A2 to B2 while rebuilding Python and AI API skills.

---

## What it does

Records a German lesson → transcribes audio → extracts vocabulary and grammar 
→ loads flashcards into Anki → generates a study PDF → updates a Google Doc 
dashboard. One command, fully automated.
